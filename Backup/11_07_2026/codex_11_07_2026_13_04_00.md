# Codex do projeto

Última atualização: 11/07/2026

## Visão geral

Este repositório contém uma análise de comportamento, dependência em jogos, saúde mental e produtividade. O fluxo principal usa um notebook Jupyter para baixar ou carregar o dataset, tratar valores ausentes, traduzir campos para português, preparar uma base para Power BI e exportar arquivos processados em CSV e XLSX.

O projeto também possui um relatório em Power BI, uma versão em PDF e prints das páginas do relatório na pasta `figures/`.

## Fluxo principal atual

1. Importa bibliotecas principais.
2. Cria as pastas `../data/processed` e `../data/raw`.
3. Baixa o dataset do Kaggle com `kagglehub.dataset_download(...)`.
4. Move arquivos baixados para `../data/raw`.
5. Carrega `../data/raw/gaming_addiction.csv`.
6. Inspeciona dados, valores ausentes e colunas.
7. Gera histogramas exploratórios com Plotly.
8. Preenche `subscription_status` com `No subscription`.
9. Preenche `addiction_severity` com `Without addiction`.
10. Converte `depression_indicator` e `gpa_or_performance_score` para numérico.
11. Preenche `depression_indicator` com mediana por `addiction_severity`, usando 4,5 como fallback.
12. Preenche `gpa_or_performance_score` com mediana por `occupation`, usando 4,0 como fallback.
13. Cria `df_powerbi` como cópia de `df`.
14. Renomeia colunas para português.
15. Traduz valores categóricos.
16. Converte colunas `float` para texto com vírgula decimal.
17. Renomeia `id_usuario` para `id_usuario_original`.
18. Insere novo `id_usuario` sequencial de 1 a 250.
19. Exporta CSV e XLSX processados.

- Não há variáveis de ambiente documentadas.

- Manter alterações pequenas e focadas no fluxo de análise.
- Evitar versionar `venv/`, caches, checkpoints e saídas temporárias.
- Preferir nomes claros e funções simples caso o notebook evolua para scripts.
- Manter `df` como base analítica e `df_powerbi` como versão de apresentação.
- Antes de alterar arquivos existentes, preservar backup em `Backup/DD_MM_AAAA`, conforme a regra operacional do projeto.

## Decisões técnicas observadas

- O notebook é o ponto central de preparação dos dados.

- A versão exportada para Power BI usa colunas em português e valores categóricos traduzidos.

## Pontos de atenção

- `subscription_status` e `addiction_severity` possuem a categoria textual `None` no CSV bruto. Com `pandas.read_csv` padrão, esse valor pode ser interpretado como nulo.
- A base processada atual contém `Sem dependęncia`, com caractere acentuado inconsistente. O ideal é revisar para `Sem dependência`.
- A categoria `Não binario` aparece sem acento em `binário` no notebook. O ideal é revisar para `Não binário`.
- A categoria `Streamer/Criador de conteudo` aparece sem acento em `conteúdo`. O ideal é revisar para `Streamer/Criador de conteúdo`.
- A conversão de decimais para texto com vírgula facilita a leitura em contexto brasileiro, mas pode exigir conversão de tipo no Power BI para agregações numéricas.
- Não há testes automatizados configurados.
- Não há manifesto de dependências, o que dificulta reproduzir o ambiente.
